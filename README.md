\# Blog Portfolio Project



A blog website with a React frontend and an Express/Node.js backend. The backend uses MongoDB to store blog posts and Firebase Authentication to protect blog creation.



\## Project folders



\- `blog-project-starter-frontend/` — React website

\- `blog-project-starter-backend/` — Express API and MongoDB connection
